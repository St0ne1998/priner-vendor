# Priner Vendor Website Terms and Conditions

This project contains the official responsive HTML and CSS terms and conditions template tailored for the **Priner** multi-vendor marketplace platform (`www.prinr.store`). 

## Features
* **Red Accent Theme:** Designed with a professional, clean layout featuring striking red accent borders and matching call-to-action buttons (`#d32f2f`).
* **Responsive Design:** Optimized layout that automatically scales gracefully across desktop computers, tablets, and mobile smartphones.
* **Legal Compliance Integration:** Formatted with structured sections covering South African regulatory standards including the Consumer Protection Act (CPA), Electronic Communications and Transactions Act (ECTA), and the Protection of Personal Information Act (POPIA)[cite: 3].
* **Interactive Navigation Actions:** Includes a dual-button action footer at the base of the document:
  * **Accept Terms:** Routes users to the vendor onboarding portal.
  * **Decline:** Safely redirects users back to the main storefront (`www.priner.store`).

## File Structure
* `index.html`: The core single-page document containing all styles, legal sections, and interactive navigation elements.

## Usage
To view or deploy the document:
1. Save the code into a file named `index.html`.
2. Open the file in any modern web browser (Chrome, Safari, Firefox, Edge).
3. Host the file directly via your cPanel hosting environment or web server directory.
